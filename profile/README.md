# 千反田 / Chitanda Project

次世代のプロキシ・ルーティングエンジンおよびクライアントエコシステム。  
高速で安定した透過的プロキシ、柔軟なルーティング、安全な通信プロトコルを提供します。

---

### 📦 主要コンポーネント

- **[Chitanda Core（コアエンジン）](https://github.com/chitanda-project/chitanda)**  
  Xray-core と Mihomo を統合した高性能プロキシコア。高度なルーティングと暗号化トンネリングを実現。

- **[Chitanda for Android（CMFA）](https://github.com/chitanda-project/chitanda-cmfa)**  
  Chitanda Core を内蔵した、直感的でパワフルな Android 向けプロキシクライアント。

- **[Chitanda for OpenClash](https://github.com/chitanda-project/chitanda-openclash)**  
  Chitanda Core を統合した OpenWrt / ルーター向けプロキシクライアント。

- **[ドキュメント / 公式サイト](https://chitanda.net)**  
  利用ガイド、設定リファレンス、およびリリース案内。
